# Qwen3.5-27B vLLM Baseline Submission

This repository is a baseline submission for the Qwen3.5-27B inference service optimization competition.

This version does not modify model weights, model architecture, tokenizer, sampling parameters, or evaluation behavior. It only starts the official vLLM service with the official Qwen3.5-27B model.

## Files

- `build.sh`: no custom build steps.
- `run.sh`: starts the vLLM baseline service.
- `env.md`: environment variable description.
- `optimization_report.md`: baseline technical report.
